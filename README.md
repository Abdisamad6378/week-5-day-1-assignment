# Week 5 Day 1 Assignment

A REST API built with **Node.js** and **Express** that manages a collection of Kenyan cities in memory. The API supports listing (with filtering), creating, and deleting cities.

## Features

- **GET /api/cities** — returns all Kenyan cities with optional filtering by county and minimum population
- **POST /api/cities** — creates a new city with input validation
- **DELETE /api/cities/:id** — removes a city by its ID
- All responses use a consistent JSON envelope: `{ success, ... }`

## Tech Stack

- [Node.js](https://nodejs.org/)
- [Express](https://expressjs.com/) `^5.2.1`

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v14 or later recommended)
- npm (bundled with Node.js)

### Installation

```bash
npm install
```

### Running the server

```bash
node server.js
```

The server starts on `http://localhost:3000` (configurable via the `PORT` environment variable).

```bash
PORT=4000 node server.js
```

## API Endpoints

### GET /api/cities

Returns a list of all cities. Supports two optional query parameters that can be combined:

| Parameter        | Type   | Description                                         |
| ---------------- | ------ | --------------------------------------------------- |
| `county`         | string | Filters by county (case-insensitive)                |
| `minPopulation`  | number | Returns cities with a population greater than value |

**Response: `200 OK`**

```json
{
  "success": true,
  "count": 8,
  "data": [
    { "id": 1, "name": "Nairobi", "county": "Nairobi", "population": 4397073 },
    { "id": 2, "name": "Mombasa", "county": "Mombasa", "population": 1208333 }
  ]
}
```

### POST /api/cities

Creates a new city. Requires a JSON body:

```json
{
  "name": "Nanyuki",
  "county": "Laikipia",
  "population": 63792
}
```

Validation rules:
- `name` — required, must be a non-empty string
- `county` — required, must be a non-empty string
- `population` — required, must be a positive number

The `id` is auto-generated by incrementing from the last city's ID.

**Response: `201 Created`**

```json
{
  "success": true,
  "data": { "id": 9, "name": "Nanyuki", "county": "Laikipia", "population": 63792 }
}
```

**Response: `400 Bad Request`** (invalid input)

```json
{
  "success": false,
  "error": "Name and county are required"
}
```

**Response: `400 Bad Request`** (invalid population)

```json
{
  "success": false,
  "error": "Population must be a positive number"
}
```

### DELETE /api/cities/:id

Deletes a city by its numeric ID.

**Response: `200 OK`**

```json
{
  "success": true,
  "message": "City deleted",
  "data": { "id": 3, "name": "Kisumu", "county": "Kisumu", "population": 610082 }
}
```

**Response: `404 Not Found`**

```json
{
  "success": false,
  "error": "City with ID 999 not found"
}
```

## Testing with curl

### Get all cities

```bash
curl http://localhost:3000/api/cities
```

### Filter by county (case-insensitive)

```bash
curl "http://localhost:3000/api/cities?county=mombasa"
```

### Filter by minimum population

```bash
curl "http://localhost:3000/api/cities?minPopulation=500000"
```

### Combine both filters

```bash
curl "http://localhost:3000/api/cities?county=kiambu&minPopulation=100000"
```

### Create a new city

```bash
curl -X POST http://localhost:3000/api/cities \
  -H "Content-Type: application/json" \
  -d '{"name": "Nanyuki", "county": "Laikipia", "population": 63792}'
```

### Delete a city

```bash
curl -X DELETE http://localhost:3000/api/cities/3
```

### Delete a non-existent city (404)

```bash
curl -X DELETE http://localhost:3000/api/cities/999
```
